Chapitre 3

L'intégrale,
c'est quoi ?

L'aire colorée sous la courbe = l'intégrale (positive au-dessus, négative en-dessous)

🟰 Idée géométrique

L'intégrale ∫ₐᵇ f(x) dx = l'aire algébrique entre la courbe et l'axe des x.

Positive au-dessus de l'axe, négative en-dessous.

🚗 Idée physique

Si v(t) = vitesse, alors ∫₀ᵀ v(t) dt = distance parcourue.

Vitesse × temps = distance. L'intégrale généralise ça.

📐 Fonction en escalier définition clé

Une fonction φ est en escalier si elle est constante par morceaux. Son intégrale, c'est juste la somme des aires des rectangles :

∫ₐᵇ φ(x) dx = Σ cₖ × (xₖ - xₖ₋₁) ↑ ↑ ↑ intégrale hauteur largeur du rectangle
✅ Quand est-ce qu'une fonction est intégrable ?

f est intégrable si l'approximation par en-dessous et par en-dessus convergent vers la même valeur : I⁻(f) = I⁺(f).

Théorème simple à retenir :
f continue ⟹ f intégrable.
f continue par morceaux ⟹ f intégrable.
Chapitre 3 · §2

Les 3 propriétés
essentielles

  1. Relation de Chasles
    ∫ₐᵇ f = ∫ₐᶜ f + ∫ᶜᵇ f On peut couper l'intervalle où on veut
  2. Positivité
    f ≤ g ⟹ ∫ₐᵇ f ≤ ∫ₐᵇ g

    + Inégalité triangulaire : |∫f| ≤ ∫|f|

  3. Linéarité
    ∫(f + λg) = ∫f + λ∫g L'intégrale se distribue sur les sommes et sort les constantes
    ⚠️ Attention : ∫(f × g) ≠ (∫f) × (∫g) en général !
Chapitre 3 · §3

Calculer une intégrale
concrètement

⭐ Théorème fondamental de l'analyse le plus important

Si F est une primitive de f (c'est-à-dire F' = f), alors :

∫ₐᵇ f(x) dx = F(b) - F(a) = [F(x)]ₐᵇ La notation [F(x)]ₐᵇ veut dire : on évalue en b, on enlève l'évaluation en a
En pratique : trouver une primitive → l'évaluer aux bornes → soustraire.
🔄 Intégration par parties (IPP)
∫ₐᵇ u(x)v'(x) dx = [u·v]ₐᵇ - ∫ₐᵇ u'(x)v(x) dx

Choisir u et v' intelligemment : u doit se simplifier en dérivant, v' doit être facile à intégrer.

Exemple type : ∫ x·eˣ dx → u=x, v'=eˣ → u'=1, v=eˣ
🔁 Changement de variable
∫_{φ(a)}^{φ(b)} f(x) dx = ∫ₐᵇ f(φ(t)) · φ'(t) dt On pose x = φ(t), donc dx = φ'(t)dt, et on change les bornes
Moyen mémo : on substitue x par φ(t), on multiplie par φ'(t), on adapte les bornes.

Formules de Taylor :
approximer une fonction

L'idée : on remplace une fonction compliquée par un polynôme qui lui ressemble près d'un point x₀.

📏 Taylor-Reste intégral

Formule exacte avec un reste exprimé par une intégrale.

f(x) = Σₖ₌₀ⁿ f⁽ᵏ⁾(x₀)/k! · (x-x₀)ᵏ + ∫_{x₀}^{x} f⁽ⁿ⁺¹⁾(t)/n! · (x-t)ⁿ dt
🎯 Taylor-Young

Formule approchée avec le reste noté o(…). C'est celle qu'on utilise pour les DL.

f(x) = Σₖ₌₀ⁿ f⁽ᵏ⁾(x₀)/k! · (x-x₀)ᵏ + o((x-x₀)ⁿ) (x→x₀)
💡 Exemple concret : eˣ en x₀ = 0
eˣ = 1 + x + x²/2 + x³/6 + o(x³) = f(0) + f’(0)·x + f’’(0)/2! · x² + f’’’(0)/3! · x³ + …

Chaque terme ajoute de la précision. Plus on en met, meilleure est l’approximation.

Chapitre 4 · §5

Développements limités
usuels en x₀ = 0

Comment lire un DL : la formule donne l'approximation polynomiale à l'ordre n. Le o(xⁿ) signifie "un reste qui s'annule plus vite que xⁿ".
eˣ
eˣ = 1 + x + x²/2! + x³/3! + ... + xⁿ/n! + o(xⁿ)
ln(1 + x)
ln(1+x) = x - x²/2 + x³/3 - x⁴/4 + ... + (-1)ⁿ⁺¹xⁿ/n + o(xⁿ)
sin x et cos x
sin x = x - x³/6 + x⁵/120 - ... + (-1)ᵏ x²ᵏ⁺¹/(2k+1)! + o(x²ᵏ⁺²) cos x = 1 - x²/2 + x⁴/24 - … + (-1)ᵏ x²ᵏ/(2k)! + o(x²ᵏ⁺¹)
Moyen mnémotechnique : sin a les puissances impaires, cos a les puissances paires.
(1 + x)ᵅ (généralisation)
(1+x)ᵅ = 1 + αx + α(α-1)/2! · x² + ... + o(xⁿ) Pour α = -1 : (1+x)⁻¹ = 1 - x + x² - x³ + ... Pour α = 1/2: √(1+x) ≈ 1 + x/2 - x²/8 + ...

Opérations sur les DL

➕ Somme

On additionne terme à terme, et le o reste le même.

✖️ Produit

On multiplie les polynômes et on tronque à l'ordre n (on jette les termes de degré > n).

🔗 Composition

Pour f(g(x)) avec g(0) = 0 : on substitue le DL de g dans le DL de f, puis on tronque à l'ordre n.

Exemple : ln(1 + sin x) → on remplace h = sin x dans ln(1+h), puis on développe sin x.
📍 DL en x₀ ≠ 0

On pose h = x − x₀, et on fait un DL en h → 0. Ça évite de recalculer toutes les dérivées.

Ex : DL de eˣ en x₀ = 1 eˣ = e^(1+(x-1)) = e · e^(x-1) = e · e^h = e(1 + h + h²/2 + h³/6 + ...) = e(1 + (x-1) + (x-1)²/2 + ...)
Chapitre 4 · §6

Optimisation en dim 1

🔍 Nature des points critiques

Si f'(x₀) = 0 (point critique), on regarde f''(x₀) :

f''(x₀) > 0 MINIMUM local (courbe "sourit" ∪)
f''(x₀) < 0 MAXIMUM local (courbe "pleure" ∩)
⚠️ Si f''(x₀) = 0, on ne sait pas (peut être min, max ou rien).
🗺️ Méthode complète sur [a, b]
  1. Trouver les points critiques : résoudre f'(x) = 0 sur [a, b]
  2. Tester la nature de chaque point critique avec f''
  3. Évaluer f aux bords : f(a) et f(b)
  4. Comparer toutes les valeurs → identifier min et max globaux
